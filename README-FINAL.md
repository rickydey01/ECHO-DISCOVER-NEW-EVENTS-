# ECHO — Final Client Demo

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm start
```

## Animation stack
- GSAP + ScrollTrigger — cinematic scroll choreography
- Lenis — smooth scrolling
- Motion — lightweight React layout/filter transitions
- React PageFlip — upcoming event ticket interaction

## Sections
1. Home — original ECHO
2. Featured Events — original ECHO cards/hover system
3. Upcoming Events — original ECHO ticket/page-flip system
4. Categories — V2 interactive category experience
5. Gallery — V2 three-row infinite horizontal gallery
6. About — V2 editorial section
7. Footer — V2 cinematic closing

The project intentionally does not ship `node_modules`. Run `npm install` once after extracting.
