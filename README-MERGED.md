# ECHO — MERGED CLIENT DEMO

This build combines:
- Original ECHO ZIP: Hero, Featured Events, Upcoming Events (including the existing card hover/expand animation and physical ticket flip system).
- ECHO V2: Categories, three-row infinite Gallery, About, Footer.
- Added global Lenis + GSAP ScrollTrigger choreography.
- Added lazy/async gallery loading and containment guardrails to reduce image-related browser work.

Run:
npm install
npm run dev

Then open http://localhost:3000
